# Logviewer for Ubuntu Touch

This application lets you view logs on Ubuntu Touch devices. Based on the original work of Victor Tuson Palau, Niklas Wenzel, Johannah Sprinz and Rudi Timmermans.

[![Logviewer](assets/logo.png)](https://open-store.io/app/logviewer.ruditimmer)

## Build

`clickable build --libs --arch [arch]`

`clickable build --arch [arch]`

## Translations

Translation hosting is provided by Weblate on their libre plan. You can contribute [here](https://hosted.weblate.org/projects/ubports/logviewer-fork/#information), not only to this app but also other Ubuntu Touch related projects.
